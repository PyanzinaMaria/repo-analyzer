# Настройка Q-learning и генетического алгоритма на HTML-стенде

На офлайн-стенде «Редактор буклета» настроенный Q-learning лучше всего исследовал граф: в первом контрольном наборе он находил в среднем 0,82 редкого предпросмотра против 0,24 у случайного обхода и покрывал 189,38 уникального перехода против 147,68. Генетический алгоритм не показал убедительного преимущества, поэтому дополнительно проверены все три гибрида.

## Протокол

- **Среда:** тот же офлайн-стенд и динамический граф; 600 выполненных действий на прогон, не более 24 действий в эпизоде. Повторное действие расходует бюджет. Полный граф и метки редких страниц не используются при выборе отдельных действий.
- **Подбор:** по 40 конфигураций на метод, seed 0–19. Целевая метрика: среднее число разных достигнутых редких предпросмотров; при равенстве выбиралась конфигурация с большим средним числом уникальных переходов.
- **Первый контроль:** seed 100–149, без изменения параметров. Сравниваются базовый обход, исходные и настроенные методы.
- **Гибриды:** seed 200–249; каждый гибрид использует фиксированное разделение бюджета 300/300 и сравнивается с отдельными методами на тех же seed. В парном 95%-м бутстреп-интервале перешкалируются разности по seed; интервалы описательные, без поправки на множественные сравнения.

## Выбранные настройки

- **Q-learning:** \(\alpha=0{,}85\), \(\gamma=0{,}4\), \(\varepsilon=0{,}45\). Награда за новое наблюдение: \(1/N(s')\), где \(N\) учитывает текущий визит. В ветви выбора по оценке используется \(Q(s,a)+2/\sqrt{1+N(s,a)}\). Q-таблица не разделяет оценки по номеру шага внутри эпизода. Отдельной абляции, которая изолировала бы вклад каждого изменения, нет.
- **Генетический алгоритм:** 6 особей, вероятность мутации позиции 0,28; на поколение 1 элитная особь, 3 потомка и 2 случайных сценария. Размер турнира 2. При оценке суммируется \(1/N(s)\) по разным посещённым состояниям сценария, кроме начального; счётчики берутся после оценки поколения.

## Первый контроль

| Метод | Редких страниц за прогон | Прогоны хотя бы с одной | Уникальные переходы за прогон |
|---|---:|---:|---:|
| Случайный обход | 0,24 | 10/50 | 147,68 |
| Исходный Q-learning | 0,20 | 10/50 | 121,32 |
| Исходный генетический | 0,14 | 7/50 | 130,78 |
| Настроенный Q-learning | **0,82** | **35/50** | **189,38** |
| Настроенный генетический | 0,26 | 12/50 | 134,16 |

Разность с базовой линией по числу редких страниц: Q-learning \(+0{,}58\), 95%-й интервал \([0{,}34;\ 0{,}80]\); генетический алгоритм \(+0{,}02\), интервал \([-0{,}18;\ 0{,}22]\). Q-learning также дал в среднем на 41,70 уникального перехода больше, интервал \([36{,}70;\ 46{,}92]\).

## Гибриды

- **Случайный → Q-learning:** первые 300 действий выбираются случайно, но используются для обучения Q-таблицы; затем выбираются настроенной политикой.
- **Случайный → генетический:** первые 300 действий выполняет случайный обход. Граф и счётчики сохраняются, а половина начальной популяции получает префиксы из наблюдавшихся маршрутов.
- **Q-learning → генетический:** тот же способ передачи графа, счётчиков и префиксов, но первый этап выполняет Q-learning.

| Метод | Редких страниц за прогон | Прогоны хотя бы с одной | Уникальные переходы за прогон |
|---|---:|---:|---:|
| Случайный обход | 0,44 | 21/50 | 146,72 |
| Настроенный Q-learning | **0,68** | **29/50** | **185,42** |
| Настроенный генетический | 0,38 | 16/50 | 136,54 |
| Случайный → Q-learning | 0,58 | 25/50 | 177,12 |
| Случайный → генетический | 0,38 | 16/50 | 139,58 |
| Q-learning → генетический | 0,54 | 23/50 | 158,20 |

Два гибрида с RL покрыли больше переходов, чем случайный обход, но ни один гибрид не обошёл настроенный Q-learning по среднему числу редких страниц или переходов. Во втором контроле численное преимущество Q-learning по редким страницам меньше: \(+0{,}24\), интервал \([0;\ 0{,}50]\); по переходам оно сохраняется: \(+38{,}70\), интервал \([34{,}08;\ 43{,}40]\).

## Воспроизведение

```bash
python -m offline_sequence_benchmarks.tuning --hybrids --output-dir output
```

В архив входят оба модуля предыдущего стенда и новый скрипт, а также CSV подбора, обоих контрольных сравнений и итоговый JSON. Эксперимент сравнивает функциональный обход одного фиксированного синтетического интерфейса с разными seed. Он не проверяет обнаружение уязвимостей и не измеряет перенос на другие графы.
